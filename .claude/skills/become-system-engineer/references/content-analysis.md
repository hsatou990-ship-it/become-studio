### 1. 複数フレームの総合評価
- 1枚の画像やタグだけで判断しない。素材ごとに、時間方向に複数フレームを抜き取る（設計上の仮定: 約3秒に1枚、最小3・最大8。未測定）。
- 評価の軸（7つ）: 台本との意味の一致、構図、被写体、光、色彩、動き、感情表現。
- 軸ごとの担当方式: 意味の一致はCLIP系（承認後）。構図・光・色彩・動きは、モデルなしの統計（承認後にコード化）。感情表現と被写体の適否は、MASTER DIRECTORの判断項目（感情曲線、素材選定、構図）を採点表にして適用。最終の美しさ・感情は人間評価。
- 連携の形: MASTER DIRECTOR が場面ごとに「意図」（感情、必要な被写体、避ける被写体、光と色の方向、動きの強さ）を設計JSONへ書く → 分析側がその意図を検索文・比較文に変換 → 候補を軸ごとに採点 → 総合順位。意図を持たない場面は、既存の提案点とsemCheckだけで動く（回帰なし）。
- 機械の総合点は「提案順位」であり、品質の保証ではない。

### 2. 自動での変更と再評価（手動確認を増やさない）
- 不適切を検出したら、まず、取得済みの候補（同じ場面の次点）へ自動で差し替え、再評価する。通信は使わない。
- 取得済み候補が尽きた場合のみ、承認済み枠の残りの範囲で、別の検索語（意図の「避ける被写体」を除外条件に反映）を使い、再取得・再評価。枠の残りを超える通信はしない（枠は絶対にリセットしない）。
- 再評価の回数に上限を置く（無限ループ防止）。上限後は確認待ち。
- 人間にしか判断できないものは維持: 権利確認、美しさ・感情・世界観の最終評価。確認待ちは、候補を使い切った場面だけ。

### 3. Androidの性能保護
- 処理順序の原則: 重い処理を同時に動かさない。分析 → 解放 → ナレーション・音声処理 → 解放 → レンダリングと書き出し。
- 分析が終わったら、モデルと中間データ（抜き取りフレーム、特徴量の大きな配列）を解放する。保持するのは、場面ごとの採点結果（小さな数値）だけ。

- 1080p書き出し（BASE-15-r11で成功）を壊さない。分析の追加で、書き出しの成功・時間・メモリが悪化した場合は採用しない。

## Transformers.js の導入方針（2026-11-28 段階B-0。SYSTEM ENGINEER の専門知識として追記。新しい独立スキルではない）
出典の限界: 公式の開発スキル（huggingface/transformers.js の .ai/skills/transformers-js/SKILL.md）は、この環境から本文を取得できませんでした（確認できません）。以下は、公式ドキュメントとモデルカード（2026-11-28 確認）と、本プロジェクトの設計方針です。取得できた時点で照合して差分だけ追記します。外部のスクリプトやインストーラは実行しません。
- 局所推論: ブラウザ内でだけ推論する。画像・台本・素材を外部へ送らない。env.allowRemoteModels=false、モデルとライブラリは同一オリジン（./models、./vendor）に配置し、CSPの接続先は 'self' のみ（測定ページ。編集画面のCSPは変えない）。
- 方式: WebGPU（Android Chrome 121以降・Android 12以上の対応GPUで既定有効。実際に使えるかは測定時に確認）と、WASM（互換用）。両方を同じ条件で比べ、片方が失敗しても安全停止する。
- 量子化: 候補Aは uint8（画像88.6MB＋文章64.1MB）を第一候補。q4f16・fp16は、uint8の精度が不足した場合にだけ比較（同時取得はしない）。
- キャッシュ: 取得済みファイルはブラウザ/Cache Storageで再利用し、再取得をしない。埋め込みは「素材・時刻・モデル版」をキーに保存して再利用。モデルの版（revision）を固定し、版が変わったらキャッシュを無効にする。
- 版の固定: ライブラリの版は取得時に確定して記録（調査で 3.8.1 と 4.3.2 の表記が食い違い、確認できません）。モデルは revision 6b7c523703ae26e39be4b03774966f8571c7f523。ファイルのSHA-256を取得後に計算し、Hugging FaceのLFS oidと照合する。
- メモリ解放: 推論後に model.dispose()、キャンバスは width=0、動画は src を外す。解放前後のJSヒープを記録（端末全体のメモリは取得できず未測定）。
- 中断と復旧: 各フレームの境目で中止を確認し、失敗時は解放して理由を残す。ページ再読み込み後も、埋め込みのキャッシュで続きから再開できる。
- 不要な通信の防止: CSP（connect-src 'self'）に加え、fetch を同一オリジンに限定。許可リスト外のアダプタを読まない。
- セキュリティと商用: ライセンス（モデル MIT、ライブラリ Apache-2.0。いずれも取得時にファイル側の表記を再確認）。ライセンスが不明、または追加費用が出る場合は停止。
- 意味理解の使い方: CLIP類似度は順位付けと除外の手がかり。肯定と除外の両方を複数フレームで評価し、「保証しない・未較正」を結果に明記する。実装: exp/cinematic-pro/ai/intent.js、測定: ai/measure.html、試験: tests/tai.py・tmeas.py。
