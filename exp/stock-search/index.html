STOCK SEARCH（実験）

Pexels／Pixabayから台本に合う縦動画の候補を探す実験ページです。BECOME. STUDIO本体とは無関係です。APIキーは画面を閉じると消え、保存・送信・表示されません。Pexels検索結果の提供元：Pexels／Pixabay

APIキーの取得方法（無料・スマホで可）

Pexels：pexels.com/api を開く → 「Get Started」→ アカウント作成またはログイン → 用途を簡単に入力 → 画面に表示される「Your API Key」を長押しでコピー。公式説明では即時発行です。

Pixabay：pixabay.com/api/docs を開く → ログイン（未登録なら無料登録）→ ページ内の「key (required)」欄に自分のキーが表示されるのでコピー。

キーは他人に見せず、チャット・URL・スクリーンショットに載せないでください。漏れたら各サイトで再発行します。
