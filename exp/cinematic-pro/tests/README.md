# 試験コード（模擬・ブラウザ試験。実機の保証ではない）

実行環境: Python + Playwright + Chrome。ローカルサーバ（python3 -m http.server 8765、リポジトリ直下）を起動して、各 tXXX.py を実行する。
- 試験用のAPIキーは、ダミー文字列（実際のキーではない）。
- 通信は、すべて模擬（pixabay の応答を差し替え）。実通信は行わない。
- 音声の試験素材（/tmp/wavfx 内の WAV）などは、試験の前に生成する必要がある（生成手順は未整備）。そのため、新しい環境では一部が、素材の準備なしには動かない。
- ts1.py: 段階1の再現と修正の確認（20件）。tret.py: 旧版から新版への更新でデータが保たれるかの確認（12件。旧版は git worktree で用意し、同じオリジンから配信する）。tab1.py: 複数場面の自動取得。
