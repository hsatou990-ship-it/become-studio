# 完成動画の品質比較 検証設計 v2（A基本／B高度／C ディレクター最適化）
作成日 2026-11-26。評価の目的: 機能数ではなく、完成動画が人の心を動かすかを比べる。

## 1. 統制条件（A/B/Cで固定するもの）
同一の台本、同一の素材（撮影クリップ）、同一のナレーション音声、同一のBGM、同一の長さ（まず15秒、次に30秒）、同一の解像度1080x1920・30fps、同一の字幕文面。変えるのは演出だけ。
作り方: CINEMATIC PRO で素材・音声を取り込んだ後、A/B/Cボタンで切り替えて3本を書き出す（ファイル名に A/B/C を付ける）。
前提: 実素材と実BGMが必要。模擬素材では下の評価1〜2は実施できない（試験としては「模擬」区分）。

## 2. 評価区分（混ぜない）
| 区分 | 内容 | 判定してよいこと |
|---|---|---|
| 模擬試験 | 合成素材・合成音源で自動検査 | 処理が壊れないか、規則どおり動くか。品質の優劣は判定不可 |
| 実機試験 | Androidで書き出し・再生 | 書き出し成功、所要時間、再生、取り込み可否 |
| 実素材評価 | 実素材・実音源の完成動画を人が見る | 品質の優劣（下の評価票） |

## 3. 採点票（100点満点・品質目標90点以上。オーナー指定の配点）
映像美20／台本と映像の一致15／冒頭の引き込み15／ナレーション15／BGM・効果音10／編集テンポ10／字幕・文字演出10／独自性5。
公開の前提（動画ごと）: 著作権・規約・セキュリティの3項目がすべて「合格」でなければ、点数に関係なく公開不可（未確認も公開不可）。
採点ページ: /exp/eval/（点数の自動合計、配点を超える入力の補正、公開可否の自動判定、答え合わせ後のA/B/C集計、台帳貼り付け用テキスト）。
自動計測（補助。合否には使わない）: 平均輝度、彩度、字幕の安全領域違反数、ナレーション区間の音量、最終無音。

## 4. 評価手順（ブラインド）
1. CINEMATIC PRO で素材・ナレーション・BGMを取り込み、「ブラインド比較セットを書き出す」を押す。3案がランダムな順で書き出され、動画P・Q・Rとして保存される（A/B/Cとの対応は画面にも出ない）。
2. 音量の差が評価に影響しないよう、3本のミックス音量（平均）を同じ値（-20dBFS）にそろえる。3本の差が0.5dBを超える場合は画面に警告が出る。素材・字幕・ナレーション・BGM・長さ・解像度は3本で共通。
3. オーナーが採点ページで動画P・Q・Rを順不同で採点し、公開前提の3項目を確認する。
4. 採点後に「答え合わせ」を押して対応を確認し、採点ページに入力して集計する。
5. 勝敗: 最高点の案。同点なら冒頭の引き込みと編集テンポの合計。結果は少人数・1回の評価なので、複数本（別台本）で再現するまで規則の確定には使わない。
6. 負けた案の理由を、演出ルールとディレクター設計の改善に反映する。
7. 15秒で確認してから30秒、60秒へ進む。
注意: 同じ人が複数回見ると慣れの影響が出る。評価は一度に3本続けて行い、再生順は毎回変える。

## 5. 実運用に向けた仮説（検証対象。結論ではない）
- 仮説1: BはAより目を引くが、重ねすぎで読みづらくなり総合では負ける。
- 仮説2: Cは演出量がBより少なくても、メリハリにより総合でAとBを上回る。
- 仮説3: 冒頭2秒の字幕演出が離脱を左右する。
仮説が外れた場合は、その結果を優先して規則を直す。TikTokの実際の視聴維持率は、投稿後の計測値でのみ確認できる（投稿はオーナー承認が必要）。
