# 完成動画の品質比較 検証設計（A基本／B高度／C ディレクター最適化）
作成日 2026-11-26。評価の目的: 機能数ではなく、完成動画が人の心を動かすかを比べる。

## 1. 統制条件（A/B/Cで固定するもの）
同一の台本、同一の素材（撮影クリップ）、同一のナレーション音声、同一のBGM、同一の長さ（まず15秒、次に30秒）、同一の解像度1080x1920・30fps、同一の字幕文面。変えるのは演出だけ。
作り方: CINEMATIC PRO で素材・音声を取り込んだ後、A/B/Cボタンで切り替えて3本を書き出す（ファイル名に A/B/C を付ける）。
前提: 実素材と実BGMが必要。模擬素材では下の評価1〜2は実施できない（試験としては「模擬」区分）。

## 2. 評価区分（混ぜない）
| 区分 | 内容 | 判定してよいこと |
|---|---|---|
| 模擬試験 | 合成素材・合成音源で自動検査 | 処理が壊れないか、規則どおり動くか。品質の優劣は判定不可 |
| 実機試験 | Androidで書き出し・再生 | 書き出し成功、所要時間、再生、取り込み可否 |
| 実素材評価 | 実素材・実音源の完成動画を人が見る | 品質の優劣（下の評価票） |

## 3. 評価票（各動画を1〜5点。理由を一言添える）
1. 最初の2秒で見続けたくなるか（離脱しにくさ）
2. 感情の流れ（低点から転換、上昇への起伏）が伝わるか
3. 演出が内容を助けているか（邪魔・やりすぎ・不自然がないか）
4. 字幕の読みやすさと安全領域（UIに隠れない）
5. 色・質感の統一感
6. 音（ナレーションの明瞭さ、BGMの音量、音割れ・急な変化の無さ）
7. 総合: これを自分のアカウントに出したいか（出す・直して出す・出さない）
自動計測（補助。合否には使わない）: 平均輝度、彩度、字幕の安全領域違反数、ナレーション区間の音量、最終無音。

## 4. 評価手順
1. オーナーが3本を順不同で見る（どれがA/B/Cかは見ない。ファイル名を伏せて並べ替える）。
2. 評価票に点数と理由を記入。ChatGPTにも同じ票で評価させる場合は、動画そのものは見られないため、オーナーの評価と書き出しデータ（自動計測値）だけを渡す。
3. 勝敗: 総合7で「出す」が多い案、同数なら項目1と3の合計が高い案。
4. 負けた案の理由を、次の改善（演出ルール・ディレクター設計）に反映する。
5. 15秒で勝ち筋を確認してから30秒、60秒へ進む。

## 5. 実運用に向けた仮説（検証対象。結論ではない）
- 仮説1: BはAより目を引くが、重ねすぎで読みづらくなり総合では負ける。
- 仮説2: Cは演出量がBより少なくても、メリハリにより総合でAとBを上回る。
- 仮説3: 冒頭2秒の字幕演出が離脱を左右する。
仮説が外れた場合は、その結果を優先して規則を直す。TikTokの実際の視聴維持率は、投稿後の計測値でのみ確認できる（投稿はオーナー承認が必要）。
